## 共同研究设计

初始对象采用现有 IM 分钟收益，分上午、下午 Session；午休和隔夜收益另属不同目标。价格、主力映射与源数据版本需要能追溯。先固定目标，再比较估计器与时钟，避免一个方法预测 RV、另一个预测混合贡献却共用排行榜。

建议将原始收益派生出三条明确区分的研究序列：全 slot 的 RV、仅 Session 内有效相邻配对的 BPV、当前首分钟 RV 加其余 BPV 的混合贡献。完整240分钟网格、缺失收益与有效配对数分别登记。零收益是观测值，缺失不是零。

历史日全日尺度只能在该日结束后供后续预测使用。训练与验证按日期推进；在每个预测时点，只使用那时可得的价格、曲线、状态和参数。不要随机打乱分钟做交叉验证。已有图表覆盖的区间属于已探索样本，最终保留段需要单独登记。

## 第一轮候选控制

第一轮先比较三个候选：现有贡献中位数基线、收益稳健尺度因子、分 Session 平滑因子。窗口可沿用30/60/120/360作为已有候选集合，但最终选择依赖验证结果，不预设360更差或30更好。动态状态和复杂预测模型放到静态基线清楚之后，避免同时改变所有维度。

Boudt 原法的尺度常数、正态化约定、SHS窗口整数取法、权重阈值与中心处理先按原文核对。若适配 A 股日间两 Session，需要记录实际变更，不能只使用方法名称而改变计算对象。

## 评价不只看曲线是否平

1. **覆盖与可用性**：共同可预测起点占比、暖机期、无效曲线、零值和失败原因，分方法报告；同时报告各自全样本与共同样本。
2. **周期残留**：同类型分钟的分位数和分位比、日内平均尺度、分 Session/状态结果。首分钟单列。
3. **稳定性**：相邻日 log 因子差、平滑度、尾盘响应速度。平滑是代价指标，不是越平越好。
4. **统计不确定性**：优先按连续交易日块重采样，保留日内和跨日依赖；每次重采样重估因子，或明确报告条件于已估因子的区间。块长和多重比较方式需在验证阶段记录。
5. **预测**：固定原始目标和共同起点，以天为汇总单位。15分钟目标重叠，分钟行数不能当独立样本数。

对非负目标 \(y\)、正预测 \(\hat y\)，可以用 \(\log\hat y+y/\hat y\) 的 QLIKE 形式，避免 \(y=0\) 时出现 \(\log y\)；损失的代理稳健理论前提另行核对。非正预测明确登记失败或采用预先规定的训练尺度下限，不在看到测试损失后临时截断。

## 模拟用于回答什么

一组已知周期且无跳跃的模拟可区分 RV/BPV 类型差异与错误周期；第二组加入跳跃比较稳健性；第三组让周期依赖状态比较窗口和动态模型；第四组加入噪声、零收益与两 Session 边界。模拟结果只验证指定生成机制下的性质，不代表 IM 市场结论。
