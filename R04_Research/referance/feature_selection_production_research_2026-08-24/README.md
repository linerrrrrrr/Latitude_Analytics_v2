# 期货高维特征与机器学习研究范式资料包

整理日期：2026-08-24

本资料包回答三个问题：

1. “高维特征 → 聚类/筛选/AE/VAE → LightGBM → 时间验证”是否属于主流研究；
2. 主流量化研究究竟从经济金融语义出发，还是从数据挖掘出发；
3. 结合当前正式项目与旧归档原型，怎样改造成有资格进入投产验证的流程。

文件说明：

- `01_最终报告.md`：完整结论、证据、项目诊断和建议实验协议；
- `02_材料索引.md`：按学术、机构、监管、社区分层的阅读材料与证据边界；
- `03_来源清单.csv`：便于筛选、排序和后续补充的结构化来源清单；
- `papers/`：能够直接、合法获取的开放论文或机构报告；若个别站点阻止自动下载，以材料索引中的 DOI/页面为准；
- `SHA256SUMS.txt`：已下载文件的 SHA-256，便于核验。

证据等级：

- A：同行评审论文、监管材料、可复现实证；
- B：机构第一方流程披露、正式开源平台；
- C：有方法细节的实践文章；
- D：匿名论坛自述，仅用于证明“有人这样做”或发现常见问题，不能证明盈利或行业占比。

最短结论：组件主流，旧实现的验证流程不合格；可投产的主流是“语义约束研究空间 + 机器学习组合弱信号 + 严格时间样本外 + 成本、风险与线上控制闭环”。
