## 目录与文件

- `referance/` 保存研究参考资料、文献和资料包，保留各资料的日期与证据边界；资料中的建议不自动成为项目规则或已验收的研究成果。资料索引见 [README](README.md#研究参考资料)。
- `a01_Methods/` 保存可复用研究方法。`bNN_Name/` 表示一个研究主题，主题内职责明确的单元使用 `cNN_Name`，各主题独立从 `c01` 编号。相关派生主题使用同级 `bNN_01_Name`、`bNN_02_Name`；派生号表示独立主题，资源用途后缀表示同一单元的附属资源。编号决定业务归属和浏览顺序，函数调用决定执行顺序。
- 每个 c 单元以 `cNN_Name.ipynb`、`cNN_Name.py` 两个维护文件为主，Notebook 与代理共享基名，必要配置最多再增加一个。demo 数据归 `cNN_Name_DemoData/`，与代码共享编号及业务词根；增加数据目录不新增 c 单元，也不占下一个编号。说明与 demo 生成代码仍写入所属 Notebook，不机械增加 README、启动器或工具模块。demo 目录不收纳正式实验缓存、模型或运行记录，实际需要保存 demo 时再创建。
- 分界采样在同一 `b03_Sampling/` 内定义两个单元：`c01_SamplingPositions` 定义轴、初始单位和位置，demo 归 `c01_SamplingPositions_DemoData/`；`c02_SamplingExecution` 定义报价、价格、保存和单图交互选择，demo 归 `c02_SamplingExecution_DemoData/`。消费位置结果时直接引用位置单元的目录。独立的 `c01_SamplingAxisCalibration` 入口已被替代，不另保留第三本校准 Notebook，也不拆成多个 b 目录。
- 收益／波动率建模统一归 `b04_ReturnVolatilityModeling/`，主题内依次为 `c01_IntradaySeasonality`、`c02_ModelObservations`、`c03_ReturnModels`、`c04_VolatilityModels`。c01 的贡献构造可独立调用，季节估计直接接受现成分钟贡献，输出多窗口每日曲线及诊断；正常因果曲线与受训练边界约束的固定初始回填分开调用，夜盘时段变化后整个夜盘重新积累历史。数值定义和接口见所属 Notebook。c02 的分钟去季节、既定采样区间汇总和输入尺度转换可独立调用；源行坐标必须对应完整采样轴，分钟内贡献按覆盖比例积分，同一 t 的训练／测试两侧连续，失败指标保留原因。c03 使用高斯 QML 联合估计六组收益模型，要求对应的平稳／可逆及有效性条件；FIGARCH 的 p、q 各支持 0 或 1。拟合、预测和观测更新可独立调用，系数和状态还原至输入尺度，更新不重新估计参数；失败不换模型、填值或重试。c04 支持 ARMA、ARFIMA、HAR、MEM，前两类复用 c03 均值算法并使用常创新方差；HAR 窗口按采样点数，NNLS 截距和系数非负但不要求平稳；MEM 为非负单序列递推及准似然估计。调用者显式指定是否要求下一步预测非负，违反时失败而不裁剪。拟合与更新使用同一套递推，具体接口见所属 Notebook。逐日和逐采样点重估的外层调度归具体实验，复用同一组模型函数，不在模型单元中硬编码日切分。
- 期限结构建模归 `b05_TermStructureModeling/`，当前入口为 `c01_TermStructureInputs`：输入值由上游指定，保持输入尺度；终点为合约 `delist_date` 的自然日末，用上海时区次日 00:00 的日界表示，最后有效日整天计入期限。剩余期限为自然经过时间的小数天，不截为整数，也不依赖到期日 Session。函数只需合约身份及 `delist_date`；缺日期和非有限输入保留失败原因，负期限排除，零期限及有限零／负输入保留；不设合约数量门槛。逐点合约、期限和值共同排列，不能独立压缩；报价可得时点保留为源 `bar_at`。同名代理只加载定义，真实 demo 使用 b03 全合约采样产物及只读正式合约日历元信息，归本单元 `c01_TermStructureInputs_DemoData/`；日末口径使用文件名参数 `delist_day_end`，生成身份和局部 Schema 均记录 `end_of_delist_date`。c02 必须核对并继承同一终点口径；实际验收及后续 NSS 单元建设状态见 [README](README.md#期限结构输入)。
- 同主题的 `c02_NSSFitting` 定义 NSS 四列基函数、曲线求值及固定 λ 的系数拟合，强制 `0 < lambda2 < lambda1`，λ 单位为每天。长期水平 β₀ 与短端水平 β₀＋β₁ 的下界由调用者按输入尺度显式指定；无约束用线性最小二乘，有约束用端点重参数化后的 BVLS，不事后裁剪系数。非空观测不设数量门槛；秩不足的有限解可保留并记录识别状态，无有效输入或求解失败按点记录，不换参数重试。系数与残差保持输入尺度，SSE／MSE／RMSE 独立返回；计算不绘图。真实 demo 直接消费 c01 全序列，系数表与保留上游失败行的拟合表归 `c02_NSSFitting_DemoData/`，验收状态见 [README](README.md#期限结构输入)。
- 同主题的 `c03_NSSCalibration` 分别定义网格构造、训练期逐点评估、同一训练点集合上的汇总、三种并列 λ 选择及独立热力图。λ₁、λ₂ 的上下限与线性步长暴露为参数；只拟合满足大小关系的候选。网格只消费 `sample_side == train`，以所有合法候选都成功的共同训练点进行公平比较，原始失败不改为大误差常数。最小误差的指标及汇总方式显式可选，默认累计 SSE；旧投票统计逐点最小 MSE 次数，平票按网格编号；旧加权采用平均 MSE 的样本标准差、指数误差权重及 log λ 几何平均，`weight_power` 显式可配，不吸附回网格。测试期固定训练期选出的 λ，通过 c02 逐点重估 β；失败选择保留状态，不自动改方法。热力图每次由 `plot_type` 选择 error、frequency 或 weight，只消费已有汇总，不触发拟合或选择。真实完整序列及产物归 `c03_NSSCalibration_DemoData/`，计算身份包含 c01、c02 及采样定义，纯绘图和展示标签不参与数据身份；具体公式、边界和实际验收见 [README](README.md#期限结构输入)。
- NSS 三单元共用 [c03_NSSCalibration.yaml](a01_Methods/b05_TermStructureModeling/c03_NSSCalibration.yaml)。完整 demo 采用 RB、`N15_gk_money_all_contracts_log_interpolate_fixed`，请求范围为训练 2010-01-01—2024-12-31、测试 2025-01-01—2026-09-30。σ 为当分钟主力合约 GK 波动率，轴增量为 σ 乘全合约成交额，采样单位为训练期平均分钟增量的 N 倍。Notebook 默认只执行每侧指定完整采样点的小样本，结果仅内嵌，不保存计算数据文件；完整计算由 c03 显式云入口执行并验收九份产物，分别归 c01、c02、c03 的 DemoData。冻结代码、输入、作业身份及回收记录归 `c03_NSSCalibration_CloudRuns/<batch>/`，不放入 DemoData。配置或输入变更后重新试算，不能沿用旧报告；实际执行状态见 [README](README.md#期限结构输入)。
- 不同独立单元连续编号；同一单元的 Notebook、代理和附属资源共享编号。采样价格图与 GH 分布图分开绘制，绘图与单图交互选择覆盖 CU、RB，N=10、15、30、60，实际分钟、成交额、GK×成交额及两种采样方式的全部 48 组；不因参考旧画法改变一次全局 log 差分的收益率定义。
- 小波分析归 `b06_WaveletAnalysis/`，`c01_WaveletTransform` 定义核组、响应求值、状态初始化、逐点更新和单段变换，代理只加载 Notebook 定义，真实产物归 `c01_WaveletTransform_DemoData/`。默认复因果 Gammatone 导数核连续递推，输入变换由上游决定，周期单位为采样点；不增加每窗口重置选项。正常分块、跨日及训练／测试划分传递同一状态；NaN／Inf 保留失败行并中断有效段，下一个有效值按恒定背景重新初始化、逐周期预热。因果核不做右侧延拓，已输出历史不因追加输入改变；提供 SST 所需复系数、模型导数、尺度权重及频率映射，重分配由 c02 定义。Morlet 为双边离线核，延拓方式由参数决定，无延拓时保留支持不足；不得作为当前时点可用特征。两种核的离散化、导数含义及响应滞后须随配置明确，各单元实际验收状态见 [README](README.md#小波分析)。
- 同主题的 `c02_Synchrosqueezing` 定义固定频率网格、瞬时频率估计及复系数重分配，默认正式 SST 使用 c01 的固定尺度求积权重并除以各频率区间宽度；`legacy_sum` 是不含两项权重的比较选项。Gammatone 的双线性模型导数使用 arctan 逆映射，Morlet 的连续核导数使用线性映射，不猜测未知导数约定。相对阈值为当前点可用尺度最大幅值乘显式比例，绝对阈值须显式选择；零系数不估频。无效物理频率及网格外贡献排除并记录，不裁剪到边缘。部分尺度不可用或局部数值失败时标 partial，全部不可用时复谱为空；全部就绪但没有纳入贡献时保留有效零谱。正式尺度权重不按当前就绪通道重估；计算不绘图、不执行 CWT，也不宣称已完成原信号重构。真实产物归 `c02_Synchrosqueezing_DemoData/`，分别保存频率网格、逐尺度频率与归属、每点复谱与状态，实际验收见 [README](README.md#小波分析)。完整序列状态调度、时刻对齐及独立单图绘制由 c03 组合调用。
- 同主题的 `c03_RollingWavelet` 以带坐标的连续采样行接入 c01 与可选 c02，定义 `WaveletSequenceState`、局部宽表 Schema、完整序列计算及独立单图。连续块传递上一结果的 `final_state`；采样编号须逐点连续、位置时刻不递减，重叠、跳号及倒退明确报错，不自动排序、补行或重置。缺失数值保留原行；正常日期、Session 和训练／测试分界不影响状态。因果可得时刻采用截至当前点的采样位置与源报价时刻最大值，并跨块携带；没有就绪尺度时为空。Morlet 仅记录整段上下文终点，不填写因果可得时刻。时间戳不因响应滞后回移。`plot_wavelet_sequence` 只读取已有序列表，由 `plot_type` 选择 CWT／SST 的幅值、能量或相位，每次只返回一张图；显示范围与色标参数不触发重算，零幅值相位为空。完整真实产物归 `c03_RollingWavelet_DemoData/`，数据身份涵盖计算、局部 Schema、实际依赖和上游产物，纯绘图独立记录来源、不参与数据生成身份；实际验收见 [README](README.md#小波分析)。
- 同主题的 `c04_SpectralFeatures` 只消费已有 c03 SST 序列表，定义纯复谱统计、坐标与信息时刻连接、局部 Schema 和独立单图。默认按频率区间宽度计算复谱平方质量，矩统计默认幅值权重；区间等权、功率矩权重、分频切点、有效频率比例、带宽分位和 partial 纳入方式均为参数。相位一致性使用加权圆周合向量长度；主频按最大功率密度选择，分位取频率中心离散逆 CDF。零谱、零扩散、零低频分母和不可表示的平方范数逐字段记录原因，不填值、加 epsilon 或改写上游状态。因果特征可得时刻继承 c03，Morlet 为空；统计不读取后续点、不重算小波。`plot_spectral_features` 根据 `plot_type` 每次返回一张已有特征图。完整真实产物归 `c04_SpectralFeatures_DemoData/`，实际验收见 [README](README.md#小波分析)。
- demo 归生产单元的 `cNN_Name_DemoData/`，每个业务配置保存一个 `<方法Notebook名>_<品种>_<YYYYMMDD-YYYYMMDD>_<关键参数>_demo.parquet`。前缀保留 Notebook 的完整基名及 `cNN` 编号；日期表示请求输出范围，两端包含，实际可用起止日在 metadata 中明确。涉及训练／测试划分的复权与采样 demo，将范围分别写为 `train<YYYYMMDD-YYYYMMDD>_test<YYYYMMDD-YYYYMMDD>`；两段相邻，合并即完整请求范围，分界日属于测试期，文件名不再重复列出整体范围。文件名不附版本号、运行批次或摘要。例如 `b01_MainContractSelection/c01_MainContractSelection_DemoData/c01_MainContractSelection_CU_20100101-20260930_ratio1.10_demo.parquet`；其复权结果位于 `b02_MainContinuousAdjustment/c01_MainContinuousAdjustment_DemoData/`，使用 `c01_MainContinuousAdjustment_CU_train20100101-20241231_test20250101-20260930_ratio1.10_log_common_demo.parquet`，同时标明上游选择门槛和本方法口径。

- 时间轴每个实际分钟的增量为 1，训练期校准得到 a=N，不补休市分钟；成交额轴和 GK×成交额轴保留各自增量定义。
- `display_sampling_demo_figures` 在价格执行 Notebook 中导出，供其他调用者复用；各配置的独立价格图、GH 图及来源信息保存为同一本 Notebook 的内嵌资源，每次调用在当前单元格显示独立的品种、N、轴、采样方式、图形类型选择器和一张图；重复调用用于多单元格对比。选择控件使用紧凑尺寸，提供本地 Windows 的当前图像复制按钮，保留原始分辨率。切换选项只替换已经生成的图像；不保留逐配置的静态双图展示单元格或替代入口。重新绘图或修改依赖后，图像来源身份与对应数据、绘图定义须一致。
- 两本采样 Notebook 默认启用 `demo_reuse_existing`：在准备完整分钟输入之前检查已保存结果，上游、参数、初始校准范围、生成定义、数值环境和内容摘要一致时直接读取，缺失或条件变化时才计算，损坏文件报错。固定与滚动结果分别判断；滚动复用或首次生成均使用固定 a。图像选择通过来源核对后读取内嵌 PNG，不重新拟合；图像缺失或来源变化时明确报错。显式关闭数据复用可重算采样；复用控制仅标记 `export`，不因控制路径变化改写生成算法身份。
- demo 的生成身份覆盖输入、参数、相关代码、运行环境和输出内容。代码摘要须明确包含算法、局部 Schema 及实际依赖，纯绘图定义不参与数据产物身份；新增依赖时同步更新摘要范围和下游核对。已有文件复读后，若生成身份和实际数据均一致，保留其字节和生成时间；仅有变化时重新写入并复读验收。
- `a02_Experiments/` 的业务一级目录按实验建立，使用 `bNN_<实验英文名>/`；实验名称和目录业务词根一致，中文标题使用对应译名。整体时间范围及训练／测试划分在本目录 `config.yaml` 的 `scope` 中明确，不从目录名推断。例如 `b01_ReturnVolatilityForecasting/` 对应“收益与波动率预测实验”。
- 每实验以 `experiment.ipynb`、代理 `experiment.py`、`config.yaml` 三个维护文件为主。实验共有输入和缓存归 `Data/`，运行记录归 `Tracking/`；这些附属资源不占 c 单元编号，不为每组参数复制代码目录。
- `01_project_collection` 的专题项目及记录保留自身归属。旧项目保持只读。尚未确认正式归属的新测试暂存 `00_draft_collection_02/tests/`，去留、复用与最终归属遵循[根级草稿区规则](../AGENTS.md#草稿区与文件收纳规则)。

## Notebook 与代理

- 各环节的业务 demo 使用已保存的真实上游行情或真实派生产物，实际调用每个对外计算函数，并检查该方法自身的数学关系、信息边界和输出。合成数据可用于边界测试，不能代替真实 demo 或据此宣称业务链路已验收。收益／波动率的逐点 demo 覆盖所选完整重采样序列，每个目标点使用此前历史重新估计参数，保留历史不足、缺失及拟合失败的位置和原因；不以几个点或一个测试日替代完整序列。

- b04 Notebook 默认在真实小范围内存试算，不生成 demo 数据文件；这项试算不替代完整 demo 验收。完整 demo 显式读取既有 RB 主力复权全部区间（2010-01-01—2026-09-30），使用 b03 的 GK sigma×全合约成交额、N=15、log_interpolate 与一次性训练期校准。全流程计算由已授权的三个串行 DLC 作业执行（季节、观测、模型），每作业 10 个 ecs.c6.large 节点及 Python 3.13 CPU 镜像。模型分片仅选择目标坐标，每点仍使用完整输入中此前历史重新拟合。Notebook 是组合调用的唯一代码来源；独立 worker 只负责已授权阶段、普通 API 查询与失败停止。完整 24 个产物先暂存核对来源、Schema、内容和全部位置，通过后安装到各 DemoData。运行记录归实验 Tracking，云 demo 与正式 1,944 项实验使用独立身份，不改写正式实验 scope。

- 数据表格遵循[数据呈现附带中文](../AGENTS.md#数据呈现附带中文)。silver 输入的标签从权威字段 metadata 生成，派生结果及诊断字段的标签在所属 Notebook 定义；`display` 只重命名展示副本，范围表的索引也附带中文。可共享的纯展示常量放在独立 `export` 单元格，不标记 `demo-dependency`，不因此重算 demo 或改变 Schema。

- Notebook 是算法和组合代码唯一来源。代理只调用 [a00_notebook_loader.py](a00_notebook_loader.py) 加载同名 Notebook 的 `export` 标签代码，不完整导出或复制算法。采集目录的 PythonExporter 规则不变。
- `export` 单元格仅放可安全导入的普通 Python 导入、常量、函数和类定义。数据读取、拟合、demo、图表、保存、认证及 DLC 提交放在未标记单元格，或封装为显式调用的函数；装饰器和默认参数也不得隐式启动这些操作。
- 加载器先校验、编译全部选中代码，再按顺序执行。它不是沙箱；运行异常不回滚已执行定义。未标记代码和已保存输出均不执行。不自动猜测导出、不执行依赖 demo、不热重载；修改 Notebook 后重启内核。
- 根定位仅使用 [.env.template](../.env.template) 的约定。命中项目根后，调用方显式将 `candidate_root / "04_Research"` 加入模块路径。代理和加载器不另搜根；云端从代码包根导入同样的模块，算法定义不依赖本地 `.env`。

## 时间范围与数据

- `scope` 明确整体范围、训练／测试区间、端点规则、时区、实际读取历史及复权计算范围；需要验证集、标签边界剔除或滚动拟合时一并固定。
- 首次运行保存 scope 快照与摘要。已有运行成果的实验不得通过配置或 Hydra overrides 改变 scope；时间口径变化建立独立实验目录，使用可区分的实验名称与编号。不同 scope 之间不引用或复用研究产物，即使数值恰好一致。
- 同一实验 scope 内复用仍须匹配品种、实际输入内容与角色、上游身份、复权口径、所用函数及依赖代码、参数，以及影响结果的拟合范围、随机设置和数值环境。文件存在不代表可复用。
- train/test 默认是同一数据的选取条件。普通中间量留在内存，只缓存昂贵且需要复用的结果。清理须保护活跃输入与保留成果依赖；不默认启动自动清理。
- 正式实验不直接消费可变 demo。silver 按[湖仓规则](../02_Market_Data/a02_Lake/AGENTS.md)和[权威契约](../config/data_contracts.py)只读使用。研究 Parquet 使用所属方法／实验的局部 Arrow Schema，写入后复读验收。
- demo、缓存、模型、预测和记录保存在研究目录，不写回正式 raw/silver，也不默认迁入湖内 gold。摘要只证明身份，严格重跑所需输入和代码版本必须仍可取得。

## 上游契约与研究校验

研究目录信任正式数据仓库已经保证的数据契约，不重复执行上游质量校验。研究层仅检查上游契约未保证、但当前方法必需的条件，以及自身处理可能破坏的结果性质。

读取仍遵守[湖仓规则](../02_Market_Data/a02_Lake/AGENTS.md)中的统一读取与转换入口、[权威 Schema](../config/data_contracts.py)、分区过滤及时间语义。未受正式仓库契约保证的输入，按其来源和方法要求校验。

已按所属方法契约验收的研究产物，在消费处确认生成身份和适用范围后，信任上游已经保证的字段、主键及业务关系，不重复上游输出验收。生成身份核对与上游变化后的重算要求仍按本文件的 demo、缓存规则执行；外部或合成输入由调用方先按来源契约校验。

具体方法须明确所需检查，例如样本选择与连接关系、所需分钟或换约锚点是否可用、决策时的信息可得性、变换后的数学关系与输出性质；这些条件不能由 Schema 一致推定。

## Hydra、MLflow 与 DLC

- Hydra 组合配置；Notebook Compose API 的对照循环显式编写，不将其称作自动 multirun 或 DLC 调度。提交前固定本批已解析配置和实际代码，运行中修改不影响已提交任务。
- 每实验的 `Tracking/mlflow.db` 保存本地记录；比较主题对应 Experiment，一组参数与随机种子的一次运行对应 Run。`artifacts/` 保存选定成果；共享数据只记引用和摘要，不逐 Run 复制。
- alipai 提交、查询、回收在 Notebook 中显式进行，不另建通用云调度器。OSS 使用 `research/<scope_id>/inputs/<input_id>/` 与 `research/<scope_id>/runs/<run_id>/`，研究输入不跨 scope 复用。代码包及下载暂存归本实验 `Tracking/staging/`。
- 本地数据库不交给云任务共同写入。提交后立即保存 DLC job ID；云端返回指标 JSON 和必要成果，本地按原 Run 登记。云成功但未回收须标明待回收，验收完成后才标记成果已完成。
- 本地暂存下载、复读及摘要校验、持久安装、运行记录确认后，远端输出才可清理。共享输入须无活跃任务使用；失败现场和未回收输出不进入普通过期清理。MLflow 软删除不等于物理文件回收。
- 安装和验证范围以 [环境说明](../environment/README.md) 为准；骨架不代表本地 Hydra/MLflow、云端代理或完整链路已经验证。长任务继承根级有界授权、独立可见监控及失败停止规则，目录创建和测试不启动计费任务。
