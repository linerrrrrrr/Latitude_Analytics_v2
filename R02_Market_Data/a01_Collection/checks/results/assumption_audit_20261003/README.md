# 采集链路假设审计

核验日期：2026-10-03。对象为 `E:\Latitude_Analytics_v2` 的 19 个正式采集入口、17 张稳定 silver 表、raw 归档、共享配置与运维完成状态。读者可从本文了解已证实的问题，再按 [106 项清单](CHECKLIST.md) 定位每个入口的前提与证据。本文是诊断记录，不修改生产契约。

**当前数据湖不能因为“已完成”、Schema 合法或测试通过，就被整体认定为业务正确。** 已确认会员汇总来源假设不成立、日线昨收含义错误、外部指数确认空后漏数、SHIBOR 周六发布日遗漏、宏观可用日期早于真正发布，以及锡指数配置实体不可用。还有若干业务身份、历史单位、时间归属和版本问题没有足够证据。

本文没有声称找到了所有可能隐藏的错误，也没有把有限样本通过写成全历史通过。清单中的每项均有检查结果和适用边界；“证据不足”仍是未关闭项。

## 需要分清的其他发现

- **GDP 是累计同比。** 2025-09 报告期 `GDP_YOY=5.2` 对应前三季度累计同比；第三季度单季为 4.8。来源 `TIME` 明示“第1-3季度”。当前数值作为累计同比与官方一致，但名字和“季度”频率不能被理解为单季同比；三个产业系列也需同样明确。[官方口径](https://www.stats.gov.cn/zwfwck/sjfb/202510/t20251020_1961612.html)
- **日线新增字段并未回填全历史。** 2,076,956 行中，2,050,937 行为旧来源，26,019 行为新来源；昨收和结算仅新来源行非空。这是契约已声明的迁移边界，不是本轮发现的文件损坏。2025 年样本的新增列为空，不能把这些空值误报成当年来源无结算数据。
- **昨收错误已出现在非空历史行。** 2026-09 湖内同合约顺序比较，13,287 个可比行中有 11,017 行的 `previous_close` 不等于前一已存事实收盘价。此处用的是“前一已存行”，不是另行宣称完成了全市场前交易日证明；7 合约真实来源对照提供了独立的昨结/昨收反例。
- **同一供应商跨频率也会矛盾。** MA2505 在 2025-02-14 日线成交额为 15,630,896,480，分钟合计为 15,636,340,720，差 5,444,240，超过 c07 现有金额容差。湖忠实保存了各自来源值。本轮没有证据决定哪一个数值应被替换。
- **铁矿石身份仍未证实。** `EMI00064805` 的页面与 JSON 只说明“铁矿石指数:综合”，不足以证明配置中的“新华中国铁矿石价格指数”。当前应标为身份未核准，不能擅自替换为另一个指数。[当前页面](https://data.eastmoney.com/cjsj/hyzs_list_EMI00064805.html)
- **raw passed 是字节归档状态。** 生意社链路按既定合同接受 HTTP200 原文；其状态不保证页面日期、表格和业务值正确。这不是授权变更该合同的理由。若下游要解析基差，还需要独立业务验收。
- **当前湖混有兼容的旧版本。** 报告日历 2,815 片为 v1.3.0、36 片为 v1.4.0；仓单 5,708 片为 v1.2.0、110 片为 v1.3.0。字段物理结构兼容；版本分布不等于数据损坏，也不应被描述为全部完成语义迁移。

## 为什么多轮测试仍然漏掉

证据支持以下技术原因，不能据此臆测每次历史审查人员的主观判断：

1. **业务前提先被写成契约，然后由同一前提生成测试数据。** 会员测试构造 `member_name=期货公司, rank=1`；真实官方分类汇总为 rank=-1/0，当前排名 API 样本不含那些汇总行。模拟样本只证明代码会处理作者假设存在的输入。
2. **验证重心偏向内部一致性。** 类型、行数、主键、事务、摘要、回滚和导出同步都很必要，但它们不能验证 `pre_close` 的经济含义，或“没有返回”是否真的意味着业务不存在。
3. **完成证明存在循环。** 输出为空→正式复读仍为空→日历记确认空→下一轮认为已完成。程序和状态互相一致，错误的来源前提没有被再次挑战。
4. **部分问题已被发现，却未成为生产验收门槛。** [2026-08-24 来源报告](../../REPORT_2026-08-24.md) 已列出锡 ID、铁矿身份、日历和可用日风险；该报告明确为非规范诊断。今天仍可复现，说明“记录风险”和“完成修改、迁移、验收”之间没有闭环证明。

因此，重复增加相同层次的检查次数，不能自动补上缺失的业务证据。今后的通过结论至少应分别回答：来源是否提供该对象、字段含义是否成立、日期集合是否正确、何时可用、怎样解释空、正式结果是否与真实正样本对应。
