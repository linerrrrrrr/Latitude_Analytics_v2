# 金融期货半自动 Notebook 实施与验收

- 主要验证运行时间：2026-09-05 01:07:22—01:13:32（Asia/Shanghai）；代码修改开始时刻未单独记录，记录归档和说明同步在其后完成。
- 目标：用户每次下载后只需从头运行同一个 Notebook；自动消化并删除 ZIP，随后输出完成结论或下一批聚宽代码与预计剩余轮数。
- 本记录不代表聚宽远端已经执行下一批，也不代表初始全量回补完成。

## 已实现

Notebook 改为线性 Run All：重载模块并清空旧状态；先检查固定 inbox，存在时调用正式导入器 write=True；数据库最终复核后只删除与已提交快照相同的那一个目录项；再按全白名单和当前时点重新规划。最后一格位于 Notebook 末尾，只输出当前计划。

剩余轮数使用与实际批次相同的候选排序和三项装包上限（来源请求、观察数、理论键数）预排全部当前待办，不使用总行数简单相除。估计包含当前批，以日历和政策不变、未来请求完整成功为前提，每次入库后重新计算。

“没有普通待办”不自动等于全量最新：只有 data_missing=0 且交易自然日日历及白名单两个频率的结构水位跟上时才显示全量覆盖；有来源确认缺失或上游日历陈旧时分别明确提示。完成提示给出次日北京时间 00:01 后的下次运行时点，并要求先同步上游日历。

## 删除安全

删除前先原子移走当前 inbox 目录项，再复读摘要。摘要与已提交快照相同才删除；如果用户在入库期间已覆盖成新文件，则把该新内容以不覆盖方式恢复；如果入口又被另一份更新文件占用，则两份新文件均保留并停止。删除、占用或恢复失败都不生成下一批，保留错误现场；不存在自动业务重试。
